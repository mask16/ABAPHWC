LR_WERKS-SIGN = 'I'.
LR_WERKS-OPTION = 'EQ'.

    APPEND LS_0170 TO LT_0170_B.

    IF LINES( LT_0170_B ) >= LC_CHUNK_SIZE.

      MODIFY ZPPT0170_BACK FROM TABLE LT_0170_B.

      " DB 반영 후 확정 지어주고 메모리를 비움 (매우 중요!)
      COMMIT WORK AND WAIT.

  IF LT_0170_B IS NOT INITIAL.

    CLEAR LT_0170_B..
  ENDIF.
