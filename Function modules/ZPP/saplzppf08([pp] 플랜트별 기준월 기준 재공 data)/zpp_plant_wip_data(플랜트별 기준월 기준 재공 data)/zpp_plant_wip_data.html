FUNCTION ZPP_PLANT_WIP_DATA .
*"----------------------------------------------------------------------
*"*"Local interface:
*" IMPORTING
*" REFERENCE(I_WERKS) TYPE WERKS_D
*" REFERENCE(I_SPMON) TYPE SPMON
*" TABLES
*" IT_TABLE STRUCTURE ZPPS0130 OPTIONAL
*"----------------------------------------------------------------------
*& Description : 제조수불부에서 재공필드를 display할때 기초재공 수량으로
*& 사용할 값을 본 펑션에서 계산하여 table 형태로 export한다
*"----------------------------------------------------------------------
* ZPPR0290, ZPPR0330의 로직을 차용함

* Global data declarations
* Global data declarations

  DATA : LS_T150 LIKE ZPPT0150.

  CHECK I_WERKS IS NOT INITIAL.

  CHECK I_SPMON IS NOT INITIAL.

  CLEAR GT_TABLE.

  SELECT SINGLE * INTO LS_T150
                  FROM ZPPT0150
                  WHERE WERKS = I_WERKS.


* 전기일자 선택기준 RANGE 구성

  CASE 'X'.
    WHEN LS_T150-REM.
      PERFORM MAKE_DATE_RANGE USING I_SPMON
                                    LS_T150.
      PERFORM MAKE_REM USING I_WERKS.
      CLEAR GT_TABLE[].
      LOOP AT GT_AUFM.
        CLEAR GT_TABLE.
        MOVE-CORRESPONDING GT_AUFM TO GT_TABLE.
        COLLECT GT_TABLE.
      ENDLOOP.

    WHEN LS_T150-PORD.
      PERFORM MAKE_DATE_RANGE USING I_SPMON
                                    LS_T150.
      PERFORM MAKE_ORDER USING I_WERKS.
      CLEAR GT_TABLE[].
      LOOP AT GT_AFPO.
        CLEAR GT_TABLE.
        MOVE : GT_AFPO-WERKS TO GT_TABLE-WERKS,
               GT_AFPO-MATNR TO GT_TABLE-MATNR,
               GT_AFPO-WIP   TO GT_TABLE-MENGE,
               GT_AFPO-MEINS TO GT_TABLE-MEINS.
        COLLECT GT_TABLE.
      ENDLOOP.
  ENDCASE.

  IT_TABLE[] = GT_TABLE[].

ENDFUNCTION.
