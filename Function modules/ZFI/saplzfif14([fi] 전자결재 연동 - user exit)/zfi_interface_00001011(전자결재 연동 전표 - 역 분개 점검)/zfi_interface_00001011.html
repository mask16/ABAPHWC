* AND GJAHR = I_BKPF-STJAH.
*
* IF SY-SUBRC = 0.
* L_ERR = 'G'.
* ENDIF.
*
* ENDIF.
*
**//3) 메세지 출력
* CASE L_ERR.
* WHEN 'B'. "Bizplay 연동 전표
*
* "반려가 아닌 경우 MESSAGE 출력
* IF ZFIT0030-STATUS NE 'R'.
* L_MSG = 'Bizplay 연동 전표입니다. 역 분개 진행하시겠습니까?'.
* MESSAGE W000(ZFIM1) WITH L_MSG.
* EXIT.
* ENDIF.
*
* WHEN 'G'. "그룹웨어 연동전표
*
* "반려/회수가 아닌 경우 MESSAGE 출력
* IF ZFIT0037-GW_STATUS NE 'R' AND
* ZFIT0037-GW_STATUS NE 'C'.
* L_MSG = '그룹웨어 연동 전표입니다. 역 분개 진행하시겠습니까?'.
* MESSAGE W000(ZFIM1) WITH L_MSG.

* ENDIF.
* ENDCASE.
