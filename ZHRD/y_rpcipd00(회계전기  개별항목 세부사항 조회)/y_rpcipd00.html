*&      Form  READ_DART
*&---------------------------------------------------------------------
*       read name of pernr out from infotype 0001
*----------------------------------------------------------------------
FORM READ_DART USING PERNR LIKE PPOIX-PERNR
                     SEQNO LIKE PPOIX-SEQNO
                     WPBPREF LIKE PPOIX-WPBPREF "pc205-apznr
                     C0REF LIKE PPOIX-C0REF     "pc20a-seqno
                     C1REF LIKE PPOIX-C1REF     "pc25x-c1znr
            CHANGING DART  LIKE PC25X-DART
                     UDART LIKE PC25X-UDART.

  DATA: MOLGA LIKE T500L-MOLGA,
        HELP_STRING(4).

  STATICS: OLD_PERNR LIKE PPOIX-PERNR,
           OLD_SEQNO LIKE PPOIX-SEQNO.

  CLEAR: DART, UDART.

* DART/UDART is only filled in Germany or US
  PERFORM READ_MOLGA USING PERNR CHANGING MOLGA.

  IF MOLGA = '01' OR MOLGA = '10'.
* READ RESULTS
    IF NOT ( PERNR EQ OLD_PERNR AND SEQNO EQ OLD_SEQNO ).
      PERFORM PAYROLLRESULTS_TO_BUFFER USING PERNR
                                             SEQNO.
      PERFORM READ_RESULT_TABLES USING PERNR
                                       SEQNO.
    ENDIF.
* EVALUATE SPLITS
    IF NOT C1REF IS INITIAL.
      READ TABLE C1 WITH KEY C1ZNR = C1REF.
      IF SY-SUBRC EQ 0.
        DART = C1-DART.
        UDART = C1-UDART.
      ELSE.
        ERRORS_LIST1-TXT = TEXT-E23.
        REPLACE '&1' WITH PERNR INTO ERRORS_LIST1-TXT.
        REPLACE '&2' WITH SEQNO INTO ERRORS_LIST1-TXT.
        WRITE C1REF TO HELP_STRING.
        REPLACE '&3' WITH HELP_STRING INTO ERRORS_LIST1-TXT.
        APPEND ERRORS_LIST1.
      ENDIF.
    ELSE.
      IF NOT C0REF IS INITIAL.
        READ TABLE DOC0 WITH KEY APZNR = WPBPREF
                                 SEQNO = C0REF.
        IF SY-SUBRC EQ 0.
