FORM CALC_AGE USING P_BEGDA P_ENDDA
                        P_AGE.

  CHECK P_BEGDA IS NOT INITIAL.

* 만나이
  IF P_BEGDA+0(4) GE P_ENDDA+0(4).
    P_AGE = 0.
    RETURN.
  ENDIF.

  IF P_BEGDA+4(4) LE P_ENDDA+4(4).
    P_AGE = P_ENDDA+0(4) - P_BEGDA+0(4).
  ELSE.
    P_AGE = P_ENDDA+0(4) - P_BEGDA+0(4) - 1.
  ENDIF.

ENDFORM.
