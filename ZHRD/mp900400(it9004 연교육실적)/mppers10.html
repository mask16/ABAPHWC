FORM modify_screen_newitf USING mess_wa TYPE hrpad_message.

  FIELD-SYMBOLS <tc> TYPE cxtab_control.
  DATA  act_tc  LIKE field_catalog-tablecontrol.

  field_list[] = mess_wa-field_list[].
  CHECK NOT field_list[] IS INITIAL.

      MODIFY SCREEN.
    ENDIF.
* Check whether there is a special representation of the field
* ex. as Q-field or on Table Control
    LOOP AT field_catalog WHERE screen_field EQ screen-name.
      READ TABLE field_list WITH KEY field_catalog-check_field.
      IF sy-subrc EQ 0.
